# M0 — Foundation (scaffold)

Exit criteria: app opens a window; DB migrated; settings roundtrip works; token can be
stored/read from Keychain; gates green.

---

## M0-T1 — Scaffold the project
**Refs:** CONTRACTS §2.
**Files:** entire repo skeleton (this is the only task allowed to create broad structure).
**Steps:** `npm create tauri-app@latest` → template **React + TypeScript (Vite)**, app name
`ade`, identifier `dev.mk.ade`. Move/rename so the layout matches CONTRACTS §2 (empty
module files with `// M<x>` placeholders are fine). Add `rustfmt.toml` (defaults) and
enable `"strict": true` in tsconfig. Add `npm test` script running `vitest run` (one
trivial passing test). Create `plan/DECISIONS.md` header if missing.
**DoD:** `npm run tauri dev` opens a window. Gates green.
**Out of scope:** any feature code, any dependency beyond what the template brings.

## M0-T2 — Add and FREEZE dependencies
**Refs:** CONTRACTS §1.
**Files:** `src-tauri/Cargo.toml`, `package.json`, lockfiles.
**Steps:** `cargo add` every crate in §1 (let cargo resolve current versions; do not pick
versions yourself). `npm install` every package in §1. Build. **Commit both lockfiles** —
from now on versions are frozen.
**DoD:** `cargo check` and `npm run build` pass with all deps resolving.
**Out of scope:** using any of the deps yet.

## M0-T3 — Database module + migration
**Refs:** CONTRACTS §4.
**Files:** `db.rs`, `migrations/0001_init.sql`, `main.rs` (init only).
**Steps:** copy §4 SQL **verbatim** into the migration. `db.rs`: open pool at
`<app_data_dir>/ade.sqlite` (create dir), `PRAGMA journal_mode=WAL` **and
`PRAGMA busy_timeout=5000`** (§4 — avoids `SQLITE_BUSY` under concurrent worker+IPC
writes), run `sqlx::migrate!()` at startup, store pool in tauri `State`.
**DoD:** unit test: migration runs on a temp file DB and the 7 tables exist
(`sqlite_master` query).
**Out of scope:** any queries beyond the test.

## M0-T4 — Error type + notification plumbing
**Refs:** CONTRACTS §6, §7 (codes, `evt:notify`).
**Files:** `error.rs`, `notify.rs`, `lib/ipc.ts` (listen only), a minimal toast component.
**Steps:** implement `AdeError` + `Serialize` as `{code, message}` (map variants → §7
codes; default `INTERNAL`). `notify.rs`: `emit_notify(app, level, code, message)`.
Frontend: subscribe `evt:notify` in `lib/ipc.ts`, push into `notifications` slice, render
a dumb toast (fixed corner, auto-dismiss 6 s, no styling effort).
**DoD:** a temporary debug command emitting a toast shows it in the UI (remove the
command before commit). Unit test for error→code mapping.
**Out of scope:** notification history UI (M6).

## M0-T5 — Settings + ui_state commands
**Refs:** CONTRACTS §7 (`setting_get/set`, `ui_state_get/set`).
**Files:** `ipc/settings.rs`, `lib/ipc.ts`.
**Steps:** straight SQLite upsert/select. Defaults live in code, not in the DB:
`sync_interval_secs=30`, `auto_branch=true`, `theme=dark`, `startup_command_global=""`.
**DoD:** Rust test: set→get roundtrip; get of unknown key returns None (and the typed
wrapper applies the default).
**Out of scope:** settings UI (M6), TOML export.

## M0-T6 — Keychain token storage
**Refs:** CONTRACTS §4 (Keychain note), §7 (`github_set_token` — storage half only).
**Files:** `ipc/github.rs` (stub), small `keychain` helpers in same file.
**Steps:** `keyring::Entry::new("ade", "github_pat")` set/get/delete. `github_set_token`
for now only stores (validation comes in M5-T1) and returns `{login: ""}`.
**DoD:** `[needs-keychain]` ignored test: set→get→delete roundtrip. Gates green.
**Out of scope:** any GitHub HTTP call.
