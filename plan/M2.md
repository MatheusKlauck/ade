## M2-T8 — Spike: end-to-end protocol test
**Refs:** CONTRACTS §12, §13, §14 (cycle order).
**Files:** `tests/sync_spike.rs` (integration test, temp DB + wiremock).
**Steps:** wire a minimal `run_cycle(db, gh, workspace)` (this becomes the M5 worker body;
put it in `sync/worker.rs`): incremental fetch → reconcile each issue → apply actions in
a transaction → outbox sender pass (with the GitHub-write functions stubbed as
recordable mocks for now). Script three scenarios:
1. **Remote close while Doing:** card in Doing; wiremock returns the issue closed →
   card ends in Done.
2. **Echo suppression:** wiremock returns the issue with `kanban:doing` matching local
   Doing and newer updated_at → card does NOT move, `remote_updated_at` bumped.
3. **Remote column change beats queued move:** outbox intent `from=Backlog, to=Paused`;
   poll brings the issue now carrying `kanban:doing` (remote moved it to Doing, ≠
   `from_column`) → intent dropped, card reconciled to Doing, `INTENT_DROPPED` emitted
   (assert via a captured notify sink, not the real app handle). **Second assertion:** an
   intent whose issue only gained a comment (same `desired_column` as `from_column`) is
   **not** dropped — the sender proceeds to the write.
**DoD:** all three scenarios green. This file is the regression suite M5 must keep green.
**Out of scope:** UI, real GitHub writes, rate budget.
